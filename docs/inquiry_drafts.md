# メーカーへの問い合わせ文面（案）

作成：2026-11-14（PM）。送るのはオーナー。名前と連絡先は自分のものを入れる。
比較評価が目的であることは隠さず、利用者として普通に聞く書き方にしてある。

## 1. ワナップ（利用申請と質問）

- 申請先：https://wanapp.jp/ の利用申請
- 申請の入力欄に書けなければ、問い合わせ欄かメールで送る。

```
埼玉県で、知人の猟師と一緒に罠の見回りの負担を減らす方法を検討している個人です。
1台購入して試したいので、利用を申請します。あわせて次の点を教えてください。

1. 本体1台の価格（税込）と送料
2. 通信費は本体価格に含まれるとのことですが、何年分（またはどれだけの通信量）が含まれますか。
   その後も使い続ける場合の費用はいくらですか
3. 通信に使う携帯会社はどこですか。設置場所が使えるエリアかを事前に調べる方法はありますか
4. 罠が作動してから通知が届くまでの時間の目安
5. 電波が届かない時、機器が故障した時、電池が切れた時は、どのように知らせが来ますか。
   機器が正常に動いていることを定期的に確認する仕組みはありますか
6. くくり罠への取り付け方法。対応する罠の種類
7. 個人でも1台から購入できますか。納期はどれくらいですか
8. 返品や保証の条件
```

## 2. スマートトラップ（huntech）への問い合わせ（任意）

- 問い合わせ先：https://huntech.jp/ の問い合わせフォーム

```
埼玉県で、知人の猟師と一緒に罠の見回りの負担を減らす方法を検討している個人です。
スマートトラップについて教えてください。

1. 個人でも1台から購入できますか。購入方法と納期を教えてください
2. 本体と月額の現在の価格（税込）、初期費用、最低利用期間、解約の条件
3. 通信に使う携帯会社はどこですか。設置場所が使えるエリアかを事前に調べる方法はありますか
4. 罠が作動してから通知が届くまでの時間の目安
5. 電波が届かない時、電池が切れた時は、どのように知らせが来ますか
6. くくり罠への取り付け方法
```
