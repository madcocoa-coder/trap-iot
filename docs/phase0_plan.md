# フェーズ0 実行計画

作成：2026-11-14（PM）／状態：オーナー承認待ち
承認されるまで、机上調査の実行には入らない。

## 1. この計画で決めたいこと

フェーズ0の出口は「進める／方向転換／やめる」の推奨。そのために次の3つに答える。

- Q1. 誰が、いくらなら払うか
- Q2. 既存製品で解決されていない不満は何か
- Q3. その不満を、個人が払える価格で確実に解決できるか

Q1は聞き取りが主、Q2は机上と聞き取りの両方、Q3は机上（通信コストと法規）が主な根拠になる。

### 先に置いておく判断の目安（案）

結果を見てから基準を動かさないために、今の時点で目安を書いておく。数字は仮置きで、承認時に直してほしい。

| 推奨 | こうなったら |
|---|---|
| 進める | 聞き取りで「既存品を知っているが買っていない／やめた」理由が具体的に出る。かつ、その理由を1台あたり初期2万円台・月額500円前後（仮）で潰せる見込みがある |
| 方向転換 | 不満はあるが、既存品の組み合わせや導入支援で解決できる。または個人は払わないが、猟友会・自治体は払う |
| やめる | 個人が買える価格で不満の少ない製品が既にある。または埼玉県で毎日の見回りが必須で、通知があっても見回りを減らせない。または聞き取りで支払う意思がほぼ出ない |

### A. 既存の捕獲通知製品

- やること：seed の7製品を公式情報で再確認。農水省の鳥獣被害対策機器情報の一覧ページを探し、未掲載の製品を追加する。
- 製品ごとに埋める項目：会社、通信方式、圏外での動作（中継・基地局の要否）、検知方式（空はじき判別の有無）、
  初期費用、月額、電池の種類と寿命、生存確認・通信断通知の有無、導入実績、
  個人が1台から買えるか（購入経路と価格の公開有無）、資料の作成年月。
- 完了条件：7製品すべてに全項目の「値」か「未確認（探した場所）」が入っている。新規に見つけた製品も同じ項目で記載。
- やらなくていいこと：製品の優劣の評価、メーカーへの問い合わせ（問い合わせが必要な項目は一覧にする）。

### B. 代替手段

- やること：次の4種類を調べる。
  1. 個人向けの低価格な捕獲通知品（通販サイトで買えるもの）
  2. 自作事例（ブログ、技術記事、同人ハード。使った部品と通信、かかった費用、続いているか）
  3. 海外の罠通知製品（日本で使えるか。技適の有無）
  4. 通信機能付きトレイルカメラを罠の監視に使う方法（本体価格、月額、電池寿命、圏外時の挙動）
- 完了条件：種類ごとに代表例3件以上、または「3件見つからなかった」と検索語。4については「罠1基あたりの初期費用と月額」を計算して示す。
- やらなくていいこと：カメラの画質比較、自作の設計案づくり。

### C. 利用者の不満と実証結果

- やること：自治体・国有林の実証報告、導入事例、レビュー、SNS、猟師のブログから、
  通知システムを使った人の不満と、導入をやめた／見送った理由を集める。
- 特に確認する点：空はじき・誤報の頻度（数字があるもの）、通知が届かなかった事例、電池切れ、
  設置の手間、費用への不満、見回りが実際にどれだけ減ったか。seed の「94%減」「3日に1回」は原資料で再確認する。
- 完了条件：不満を種類別に整理し、それぞれに出典と「誰の声か（自治体担当／猟友会／個人）」を付ける。
  空はじき仮説を支持する情報と、支持しない情報の両方を探した結果を書く。
- やらなくていいこと：製品の仕様整理（Aの担当）。

### D. 法規と行政指導

- やること：
  1. 埼玉県と小鹿野町で、通知システムがあっても毎日の見回りを求められるか。
     県の鳥獣保護管理事業計画、狩猟者向け資料、捕獲許可の条件、小鹿野町の鳥獣被害防止計画を確認する。
     狩猟（猟期）と許可捕獲（有害鳥獣捕獲）で扱いが違うかも見る。
  2. 国の指針と、他県の扱いの例（緩和している県、していない県）。
  3. 後付けセンサーが罠の法定要件（くくり罠の構造基準、標識など）に触れないか。
  4. 電波法。技適済みモジュールを組み込んだ機器を売るときの条件、特定小電力やLoRaの利用条件。
- 完了条件：1〜4それぞれに「公開資料で確認できた／できなかった」を明記。
  確認できなかった項目は、オーナーが窓口に聞くための質問文（どこに、何を聞くか）を付ける。
- やらなくていいこと：法解釈の断定。条文と資料の記載を引用し、解釈が分かれる点はそう書く。

### E. 市場の大きさと猟友会・補助金ルート

- やること：
  1. わな猟免許の所持者数と年齢構成（全国、埼玉県。分かれば秩父地域）。登録者数の推移。
  2. 許可捕獲に従事する人の数、捕獲報奨金の水準（埼玉県、小鹿野町）。
  3. 鳥獣被害防止総合対策交付金など、ICT機器が補助対象になる条件、補助率、申請主体。
  4. 個人が使える補助があるか。
- 完了条件：1〜4に数字と出典。「個人猟師のうち、罠の見回りに困っていそうな層」の人数を推定で示す（計算の前提を明記）。
- やらなくていいこと：売上予測、事業計画。

### F. 通信方式と1台あたりコスト

- やること：LTE-M／NB-IoT、LoRa（自営・LoRaWAN）、Sigfox、特定小電力（429MHz・920MHz）、衛星IoT、
  ELTRES などについて、次を整理する。
  技適済みモジュールの国内価格（1個購入時）、通信料（少量データ・月額）、
  山間部での到達性に関する公開情報、中継機の要否、電池寿命の目安、サービス終了リスク。
- 加えて：小鹿野町周辺の各キャリアのエリアマップを確認する（山側は未確認扱いでよい）。
- 完了条件：方式ごとに「罠1基あたりの初期費用と月額」を、罠1基・5基・20基の3ケースで推定（計算の前提を明記）。
- やらなくていいこと：回路設計、方式の最終選定。

### 調査のあとの流れ

1. opus-reviewer が6本の数字と出典を照合する（結論を左右する数字を優先）。
2. haiku-formatter が競合比較表を整形する（A・Bの内容を写すだけ）。
3. PMが聞き取り結果と合わせて docs/phase0_report.md に統合する。
4. opus-reviewer が統合レポートをレビューし、指摘に対応してからオーナーに出す。

## 3. 一次調査（聞き取り）

- 質問票：docs/interview_guide.md／記録用：docs/interviews/_template.md
- 対象：協力猟師と、その知人。目標は3〜5人。1人でも始める価値はあるが、価格の話は1人だと根拠が弱い。
- 所要：1人20分。電話でも可。
- 協力猟師へのお願いは1回にまとめる：聞き取り、知人の紹介、
  「いつもの見回りのついでに、罠の場所でスマホのアンテナ本数をメモ」の3点。追加の山行きは頼まない。
- 順番：机上調査の中間結果（特にDの行政指導）を見てから聞き取りに行くと、質問を絞れる。
  ただし日程調整は先に始めてよい。

### 既製品を比較用に買うか

提案：買う。ただし、機種の決定と発注は机上調査のあとにする。

- 理由：カタログでは分からないこと（設置の手間、通知の遅れ、圏外時の挙動、空はじきの実際、アプリの使い勝手）が、
  自分で使うと分かる。Q2の根拠として聞き取りの次に強い。
  協力猟師に「これを使ってみてどう思うか」を聞く材料にもなる。
- 候補：基地局が不要で個人が1台から買えるもの。seed ではスマートトラップ
  （本体33,800円、月980円、税抜。未再確認）が該当しそう。
  加えて通信トレイルカメラを1台。猟師にとって一番手近な代替手段のはずで、これに勝てないなら事業にならない。
- 進め方：調査A・Bが終わったら、機種、金額、買って確かめる項目を見積もりとして出す。そこで承認をもらう。
- 注意：罠への設置は協力猟師に頼むことになる。購入品のテストは、フェーズ4の現地テストと同じ日にまとめる案もある。
  どちらにするかは見積もりのときに提案する。

## 6. オーナーに確認したいこと

1. この計画で進めてよいか。直したい所があれば教えてほしい。
2. 聞き取りは何人くらいできそうか。協力猟師のほかに紹介してもらえる当てはあるか。
3. 予算50万円に、小鹿野町までの交通費と協力猟師への謝礼を含めるか。含めるなら配分を組み直す。
4. 既製品の購入は「机上調査のあとに見積もりを出し、そこで承認」の進め方でよいか。
5. 何をもって「やる価値あり」とするか。副業として小さく黒字になればよいのか、
   いずれ本業にできる規模を目指すのか。1章の判断の目安が変わる。
6. 1章の目安の数字（初期2万円台、月額500円前後）は仮置き。感覚と違えば直してほしい。
