## 3つの問いへの、今の時点の見立て

### Q1. 誰が、いくらなら払うか — まだ答えられない

- 分かったこと：わな猟免許は全国119,500件（2021年度）。実際に猟期に登録しているのは約半分の59,472人。
  埼玉県は免許1,702件に対して登録447人。
- 推定：見回りに困っていそうな層は、全国で約1.2万〜4.8万人、埼玉県で約90〜680人。
  幅が広いのは「実際に罠を掛ける割合」「見回りが負担な割合」に統計がなく、仮の値を置いているため。
- 団体ルート：交付金を申請できるのは協議会や市町村で、個人は直接申請できない。
  小鹿野町は鳥獣被害対策実施隊が未設置（令和7年4月末）。近隣では飯能市が令和7〜9年度のモデル地区。
- 未確認：いくらなら払うか。これは聞き取りでしか分からない。

### Q2. 既存製品で解決されていない不満は何か — 「価格」より「通知を信用できるか」にありそう（推定）

- 価格は、想定していたほどの穴ではない。個人向けに価格を公開している製品が既にある。
  - スマートトラップ：本体33,800円、月980円（税抜）。公式サイトに「個人様を含め」と記載。
  - アイホスエコ：42,000円、通信3年込みで月額なし。ただし購入ボタンの位置に「Sold out」表示。
    通知は「朝6時と夜22時」とあり、即時ではなさそう（日本語の原文は未確認）。
- 通知の信頼性には、公的な実証で問題が出ている。
  - 静岡県の国有林（17日間、30基ずつ）：通知6件のうち誤報4件、作動3件のうち通知漏れ1件。
    seed の「見回り94%減」はこの実証の数字で、通知がない罠を見に行かない運用の結果。
    同じ報告に、子機の故障で連日通知、中継器の停止で通知が届かない、経年劣化で不具合が年々増加、とある。
  - 長野県の国有林（令和6年度）：誤作動が多く、通知があっても毎日見回りになった。
    （2026-11-14 訂正：機器故障の3件は、初版では長野県の項に書いていたが、正しくは静岡県の報告の内容）
  - 飯能市（令和7年度）：冬は電池寿命が極端に短くなる。
- 通信断（圏外・不達）に利用者が気づける仕組みを明記した資料は、どの製品にもなかった。
  「ない」と確認できたわけではなく、書かれていないだけ。
- 空はじき仮説の根拠は弱〜中。課題と認める公的資料はあるが、頻度の数字はどこにもなかった。
  静岡で一番多かった誤報の原因は、空はじきではなく設置方法（紐の長さ）。
  空はじき判別を明記している製品は ICTハンティング装置だけ。
- 未確認：個人猟師の一次の声。レビュー、SNS、ブログでは見つからなかった（開けていないサイトが多い）。

### Q3. 個人が払える価格で確実に解決できるか — 部品代は収まりそう。確実性は未確認

- 罠から携帯回線（LTE-M）で直接送る方式が一番安い。通信部の部品は罠1基あたり約8,800円、
  月額は約143円（データ量を月40KBと仮定した推定）。罠場にKDDIの電波が届くことが前提。
- 電波が届かない罠場では、罠から LoRa で中継し、受信機だけ携帯回線につなぐ。
  通信部の原価は、受信機1台で罠5基なら1基あたり約12,600円、20基なら約8,400円（推定）。
  罠1基だけだと3万円台で、目安を超える。受信機の電源と筐体の12,000円は出典のない仮定。
- 衛星は日本では使えない（SORACOM の公式資料の対応地域に日本がない）。
  Sigfox は提供元が「山間部などは利用できない場合がある」と明記。
- 未確認：山の中で実際に電波が届く距離、電池寿命の実測。公開の実測が見つからず、現地で測るしかない。
  ケース、電池、センサー、組立の手間は上の数字に入っていない。
- 通信トレイルカメラは罠1基あたり初期約5万〜7万円で、価格では直接の脅威になりにくそう。
  ただし電池・SDカード・金具は計算に入っておらず、一部のSIM月額は仮置き。

## 事業の前提に関わる、一番大きな未確認事項

**埼玉県は「毎日わなを見回ること」を指導している。通知機器を使う場合の扱いは、どの資料にも書かれていない。**

- 出どころ：イノシシとニホンジカの第3次第二種特定鳥獣管理計画（令和4〜8年度）、
  県が掲載する狩猟免許更新講習の資料、捕獲許可の条件（第13次鳥獣保護管理事業計画に「許可条件に、見回りの実施方法等を付す」）。
- 鳥獣保護管理法と施行規則の条文には「見回り」の語がない。
- 見回りの緩和を認めた県の通知は、開いた範囲では見つからなかった。
- 静岡県は「通知の有無にかかわらず原則毎日」と指導している（林野庁の資料に記載）。

「毎日の見回りが必須で、通知があっても減らせない」なら、計画1章の目安では「やめる」に当たる。
ただし、製品の価値を「見回りを減らす」ではなく「かかったらすぐ分かる」「見回りの順番を決められる」
に置き直す道もあるので、窓口と協力猟師の答えを聞いてから評価する。
