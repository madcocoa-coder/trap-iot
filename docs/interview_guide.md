# 聞き取り質問票（20分版）

作成：2026-11-14（PM）

メモをそのまま貼ってもらえれば、記録への整形はPMがやる。

## 聞き方のコツ

- 「こういう製品があったら欲しいですか」は最後まで聞かない。人は目の前の相手に「欲しい」と言いがち。
  先に、いま実際にやっていること、払っているお金を聞く。
- 「普段は」より「一番最近は」「先週は」で聞く。具体的な回数や時間が出てくる。
- 製品の構想は Q12 まで説明しない。先に話すと、困りごとの答えがそちらに寄る。
- 沈黙は待つ。答えを言い換えて誘導しない。
- 数字は幅でいい（「30分〜1時間」）。分からなければ「分からない」と記録する。
- 録音できるなら許可を取って録音する。無理ならメモで十分。

## 時間がない時の5分版

★の付いた5問だけ聞く（Q3、Q5、Q7、Q9、Q13）。

## 質問

### 1. 基本（2分）

- Q1. 罠猟は何年目ですか。猟期の狩猟ですか、有害鳥獣捕獲（町や猟友会からの依頼）ですか、両方ですか。
- Q2. いま何基の罠をかけていますか。箱罠とくくり罠はそれぞれいくつですか。主に何を獲っていますか。

### 2. 見回りの実態（5分）

- ★Q3. 一番最近の見回りを教えてください。何時に出て、何基を回って、どれくらいかかりましたか。移動手段は。
- Q4. 見回りはどれくらいの頻度ですか。行けない日はどうしていますか（誰かに頼む、罠を閉じる、など）。
- ★Q5. 見回りで一番困っていること、やめたいと思うことは何ですか。
  （出てこなければ：時間、ガソリン代、体力、仕事との両立、天気、のどれが近いか）
- Q6. 行ってみたら罠が作動していたのに獲物がいなかった、ということはどれくらいありますか。
  10回作動したら何回くらいですか。その時はどう感じますか。

### 3. 行政と猟友会（2分）

- ★Q7. 見回りの頻度について、県、町、猟友会から何か言われていますか。
  「毎日」と言われているなら、誰から、どんな形で（講習、書面、口頭）ですか。
  通知装置があれば減らしてよい、という話を聞いたことはありますか。

### 4. 電波と現場（3分）

- Q8. 罠の場所でスマホはつながりますか。キャリアはどこですか。
  つながる罠とつながらない罠は何基ずつくらいですか。雨や霧で変わりますか。
  つながらない罠から、つながる場所までどれくらい離れていますか（歩いて何分、見通しはあるか）。

### 5. 既存の製品（4分）

- ★Q9. 罠が作動したら知らせてくれる装置を、知っていますか。使ったことはありますか。
  - 使っている／使っていた：どの製品ですか。いくらでしたか。誰が買いましたか（自分、猟友会、町）。
    良い点、不満な点は。やめたなら、なぜやめましたか。
  - 知っているが使っていない：なぜ使っていませんか。
  - 知らない：（そのまま次へ）
- Q10. 周りの猟師で使っている人はいますか。評判はどうですか。
- Q11. トレイルカメラは使っていますか。通信機能つきですか。月にいくら払っていますか。

### 6. お金（3分）

- Q12. 罠猟に年間どれくらいお金を使っていますか（罠、エサ、ガソリン、登録費など、ざっくり）。
  罠は1基いくらくらいのものを使っていますか。
  - ここで構想を一言だけ説明する：
    「今ある罠に後から付けて、作動したらスマホに知らせる装置を考えています」
- ★Q13. 自分のお金で買うとしたら、1基あたり本体いくらまで、月々いくらまでなら出しますか。
  何基に付けますか。全部ですか、遠い罠だけですか。
  「それ以上なら絶対買わない」金額はいくらですか。
- Q14. 知らせが来なかった、または間違って来た、が何回あったら使うのをやめますか。

### 7. 締め（1分）

- Q15. ほかに罠猟で困っていること、こういうものがあれば、ということはありますか。
- Q16. 同じ話を聞かせてくれそうな人を紹介してもらえますか。特に、通知装置を使ったことがある人。

## 協力猟師にだけ追加で聞くこと（現地テストの準備）

時間が余ったら。別の機会でもよい。

- 罠を置いている場所の大まかな位置（山のどちら側、標高、車を降りてからの距離）。
- 罠の周りで、装置を固定できそうなもの（木、杭）はあるか。動物にいたずらされた経験は。
- 猟期と、罠をかけている期間。現地テストに付き合ってもらいやすい時期と、避けたい時期。
- 罠の作動部分の写真を撮らせてもらえるか（センサーの取り付け方を考えるため）。

## 各質問が何に使われるか

| 質問 | 使い道 |
|---|---|
| Q1, Q2 | 回答者の位置づけ。有害捕獲か狩猟かで、見回り義務と補助の扱いが変わりうる |
| Q3, Q4, Q5 | Q2（解決されていない不満）。見回りの負担が本当にボトルネックか |
| Q6 | 仮説「空はじきの判別が差別化になる」の検証 |
| Q7 | 未確認事項「埼玉県・小鹿野町の行政指導」 |
| Q8 | 通信方式の選択。中継機が要るか |
| Q9, Q10, Q11 | 仮説「個人には既存製品は高い、または導入が面倒」の検証 |
| Q12, Q13 | Q1（誰がいくら払うか） |
| Q14 | 通知の確実性に求められる水準 |
